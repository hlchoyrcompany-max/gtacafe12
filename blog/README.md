# 달콤라떼 블로그

GitHub Pages에서 운영하는 정적 블로그입니다. 서버·회원가입·실시간 댓글 저장 기능은 없습니다. 현재 원고는 공개 설정이 꺼져 있습니다. 정적 데이터 파일과 GitHub 저장소 자체의 비공개 여부는 별개입니다.

## 파일 구성

- `index.html`: 블로그 홈
- `board.html`: 게시판과 검색
- `post.html`: 게시글·댓글·공유
- `editor.html`: 글·서식·사진·프로필·표시 수치 편집
- `preview.html`: PC에서 초안 미리보기
- `JL3jZVy984sIQ2127drz/index.html`: 기존 랜덤 주소 호환 페이지
- `blog-data.js`: 글·사진 경로·댓글·프로필 데이터
- `content.js`: 편집기에서 새 글을 만들 때 사용하는 기본값
- `js/`, `css/`: 위 페이지가 사용하는 코드와 스타일
- `assets/images/image/`: 사용자가 업로드한 본문 사진
- `tests/`: 데이터·주소·서식 처리 검증

## 글 수정

1. editor.html을 열고 수정할 글을 선택합니다.
2. 한 본문 편집창에서 글을 작성하고 선택한 글자의 굵게·색상·형광펜을 바꿉니다.
3. 사진 넣기, 인용구, 출처, 링크 카드 도구를 사용할 수 있습니다.
4. blog-data.js 다운로드 후 저장소의 같은 파일을 교체합니다.
5. GitHub에 반영하면 Pages 배포 후 적용됩니다.

전체 초안 저장은 현재 브라우저에만 저장합니다. 공개 글 체크박스가 꺼져 있으면 홈·게시판·직접 게시글 주소에 표시하지 않습니다.

## 사진과 링크

현재 원고의 사진 33곳은 assets/images/image 안의 파일을 참조합니다. 02,04.png는 두 곳에서 사용하며 22번 파일은 없습니다. 이미지 연결 시 번호를 임의로 다시 매기지 마세요.

편집기의 사진 넣기는 새 사진 데이터를 글 파일에 포함합니다. 파일 크기가 커지는 것을 피하려면 사진을 이미지 폴더에 올리고 사진 URL에 상대 경로를 입력하세요. 예: assets/images/image/35.jpg.

링크 카드는 랜딩 URL·제목·설명을 직접 입력합니다. 게시글에서 클릭하면 지정한 URL이 새 탭으로 열립니다. UTM이 포함된 URL도 보존됩니다.

## PC에서 확인

```powershell
python -m http.server 8081 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8081/editor.html 로 접속합니다. 서버 종료는 Ctrl+C입니다. 변경이 보이지 않으면 작성 중인 내용을 먼저 저장하고 Ctrl+F5로 새로고침하세요.

## 검증

```powershell
node --test tests/*.test.cjs
```

불필요한 Windows 파일인 Thumbs.db와 Desktop.ini는 Git에서 제외합니다. 이전 상태는 Git 기록에서 확인할 수 있습니다.
